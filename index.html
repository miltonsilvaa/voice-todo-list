🎙️ VoiceTasks

Uma lista de tarefas que você controla falando — usando a Web Speech API nativa do navegador, sem nenhum serviço externo de reconhecimento de voz.

Clique no microfone e diga um comando

Comandos de voz reconhecidos (em português):

  • "Adicionar comprar leite" — cria uma nova tarefa
  • "Concluir comprar leite" — marca uma tarefa como feita
  • "Remover comprar leite" — apaga uma tarefa
  • "Limpar tudo" — apaga todas as tarefas
